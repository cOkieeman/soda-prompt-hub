第一次使用？查看 5 步指南
01先写想法或选 OC在创作台新建项目，也可以先从角色库导入 OC Manager JSON。
02找提示词和参考图去提示词库或智能检索，挑选服装、动作、构图、灯光和画风。
03整理两种 Prompt同一份创作意图分别检查 Anima 标签和 Krea 2 自然语言版本。
04需要时交给 Windows 出图Windows 开机并运行 Worker 后再发送；离线时可以继续整理本地内容。
04连接本机 ComfyUI 出图Worker 随启动器自动运行；在启动器设置中填写 ComfyUI 地址，无需配对其他设备。
04连接本机 ComfyUI 出图Compute Worker 通过本地桥接目录领取任务；把 worker-config.json 的 comfyui_url 指向本机 ComfyUI 即可，无需配对其他设备。
05精选、打标并交付数据集结果图导入后人工筛选，检查 WD14 草稿，最后冻结并导出版本。

第一次使用 · 资料准备

把推荐提示词资料装到本机

这些资料会从公开 Git 仓库下载到个人资料目录，并建立本地检索索引。不会上传你的创作、角色或图片。

等待开始

Soda Prompt Hub：创作、资料引用、双格式输出、远程出图、结果回流与数据集交付已经形成完整闭环。

设备分工：Mac 负责整理、审核与保存记录； __PROMPT_HUB_DEVICE_NAME_HTML__ 的 ComfyUI 负责生成与测试。

Windows 单机模式：创作、审核与数据保存都在这台电脑完成；启动器自动管理 Worker，只需连接本机 ComfyUI。

Linux 本机模式：创作、审核与数据保存都在这台电脑完成；Compute Worker 通过本地桥接目录交换任务，只需连接本机 ComfyUI。
