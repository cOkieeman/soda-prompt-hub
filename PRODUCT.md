# Soda Prompt Hub

Soda Prompt Hub is a local image creation and dataset preparation application.
Its primary user manages prompt materials, local ComfyUI workflows, NovelAI,
image API tools, and training datasets on Windows.

The primary navigation is Creation, Gallery, Prompt Library, Search, Characters,
Datasets, LoRA Projects, and Settings. Creation switches between ComfyUI,
NovelAI, and an extensible Agent conversation. Images enter a shared gallery
and can be selected into named datasets for curation, caption review, and export.

Use the existing warm dark surfaces, cream text, acid-yellow selection, and
brick-red primary actions. Generation layouts follow NAI Launcher v4.3.1.
The prompt library follows Soda Prompt Library's category tree, dense complete
image thumbnails, and selected-material composition panel.

Support Simplified Chinese, Traditional Chinese, and English. Preserve drafts,
routes, filters, selection, and task state across navigation and refresh.
Verify rendered interactions, contrast, responsive layouts, and data recovery.
Local GPU inference is started through explicit user actions in the application.
